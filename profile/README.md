Kizz is deliberately still taking shape. We are exploring product engineering,
agent capabilities, developer infrastructure, and applied AI research instead
of forcing everything into one category too early.

The common thread is simple: build real systems, measure what happens, publish
what can be shared, and let evidence—including negative and inconclusive
results—change the next version.

### Research direction

We want to move further into open, reproducible research around agent systems:

- which models, tools, skills, prompts, and workflows work for which tasks;
- when multi-agent systems help, when they only add cost, and why;
- how agent capabilities can be tested, compared, and recursively improved;
- how research can produce useful open-source capabilities rather than only
  papers or benchmark numbers.

There is no final roadmap yet. Kizz is a place for building several credible
directions, publishing the strongest ones, and retiring or reshaping the rest.

### Paused and evolving
